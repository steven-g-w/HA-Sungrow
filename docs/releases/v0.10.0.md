Adds an **Energy management mode** control, which forced
charging/discharging needs. Safe to update from 0.9.x; the new entity is
added disabled like the other controls.

## New

- **Energy management mode** select (parameter 10003) on the hybrid
  inverter, with *Self-consumption* and *Compulsory*. According to
  Sungrow's API docs, the **Charging/discharging command** and **power**
  only take effect outside Self-consumption mode. Before this release
  there was no way to leave it from Home Assistant.

  To force-charge or force-discharge: set the mode to *Compulsory*, set
  **Charging/discharging power**, then choose *Charge* or *Discharge*. The
  inverter stays there until told otherwise, so switch the mode back to
  *Self-consumption* when done. For a timed boost, use a Home Assistant
  script with a `delay` step. It's also worth adding an automation that
  restores Self-consumption when Home Assistant starts, in case a restart
  interrupts the script.

  *External dispatch* and *VPP* modes are deliberately not offered: they
  need a continuous EMS heartbeat that this integration does not send.

  The entity only appears if your inverter reports parameter 10003. Option
  labels come from the inverter, so they may be worded slightly
  differently.

## Changes

- Select controls now treat their `catalog.yaml` options as an allowlist.
  The inverter's own labels are still used, but only for values the
  catalog lists. This keeps modes the integration doesn't support out of
  the dropdown. The existing Charging/discharging command select is
  unaffected.
